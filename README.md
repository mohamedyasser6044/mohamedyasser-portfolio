# Mohamed Yasser Kamal — Portfolio

Single-page portfolio site covering experience, projects, and skills, built from Mohamed's CV.

## Contents
- `index.html` — page structure and content
- `styles.css` — visual design (navy/amber industrial-ledger theme, nods to warehouse & supply-chain work)

## View it locally
Just open `index.html` in a browser — no build step needed.

## Publish with GitHub Pages
1. Push this repo to GitHub (e.g. as `mohamedyasser6044/portfolio`).
2. In the repo, go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and `/ (root)` folder, then **Save**.
4. The site will be live at `https://mohamedyasser6044.github.io/portfolio/` within a minute or two.

## To update
- Edit `index.html` for content (jobs, projects, contact info).
- Edit `styles.css` for colors, type, or spacing — the palette and fonts are defined as CSS variables at the top of the file.
